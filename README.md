
# Distributed Information System — Music Streaming

A distributed information system for a music streaming platform, developed using Java EE and communication between multiple subsystems.

## Technologies

- Java EE
- JPA
- JMS
- REST APIs
- MySQL

## Architecture

The system consists of a central REST server and three subsystems communicating through JMS message queues.

## Key Concepts

- Distributed application architecture
- REST-based communication
- Asynchronous messaging using JMS
- Database persistence using JPA
- Communication between independent subsystems

## Project Structure

- `java aplikacije/` — Java application components
- `baze/` — Database-related files
- `uml/` — UML diagrams

## About

Academic project developed for the Information Systems course at the University of Belgrade, School of Electrical Engineering.
